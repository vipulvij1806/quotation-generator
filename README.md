## 🚀 Usage
1. Clone or download this repository.
2. Place your logo in `assets/logo.png`.
3. Open `index.html` in your browser.
4. Fill in client details, select services, and adjust rates/quantities.
5. Totals update automatically.
6. Click **Download PDF** to save the quotation.

---

## 🌐 GitHub Pages Deployment
You can host this project live using GitHub Pages:
1. Go to **Settings → Pages** in your repository.
2. Under **Source**, select `main` branch and root folder.
3. Save.

## 🛠️ Customization
- Update service names and default rates in `index.html`.
- Adjust styling in `style.css` to match your brand.
- Extend `script.js` for advanced features (multiple dates, event blocks, tiered pricing).
